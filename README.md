# YT Media Downloader 🚀

**YT Media Downloader** es una aplicación de escritorio ligera, moderna y libre de anuncios diseñada para descargar audio y video de YouTube con la máxima velocidad y calidad disponible. 

Construida con **Python**, **CustomTkinter** y el motor de **yt-dlp**, ofrece una interfaz limpia que realiza descargas directas desde la fuente, sin acortadores de enlaces, ventanas emergentes ni demoras.

---

## ✨ Características

* ⚡ **Sin anuncios ni rastreadores:** Descargas directas de servidor a cliente.
* 🎧 **Soporte de Audio:** Extracción directa a formato **MP3** (192 kbps).
* 🎬 **Soporte de Video:** Descarga de video en alta definición en formato **MP4**.
* 🎨 **Interfaz Moderna:** UI limpia con modo oscuro usando CustomTkinter.
* 📊 **Indicador de Progreso:** Muestra la velocidad de descarga y el porcentaje en tiempo real.
* 🧵 **Ejecución Asíncrona:** La interfaz no se congela ni se bloquea durante las descargas.

---

## 🛠️ Requisitos Previos

Si deseas ejecutar el código fuente desde tu entorno local, necesitas contar con:

1. **Python 3.10+**
2. **FFmpeg** instalado y configurado en el PATH de tu sistema (requerido para procesar el audio e integrar video/audio en HD).
